# Act I pictures and videos

Each scene shows a picture or video pinned at the top, with the text scrolling beneath it.
Until you add a file, the scene shows a placeholder that says what to upload.

To replace a placeholder, add a file here named exactly like the scene, with one of these endings:
`.mp4` or `.webm` (short, silent, looping), or `.jpg`, `.png`, `.webp` (wide, about 16:9, at least 1280 pixels across).
